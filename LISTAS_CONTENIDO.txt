================================================================================
GUÍA DE ARCHIVOS DE LISTAS — D&D Homebrew App
================================================================================
Edita estos archivos en el proyecto y vuelve a hacer build, O usa la UI
homebrew de cada página (se guarda en localStorage del navegador).

--------------------------------------------------------------------------------
1) CONJUROS
   Archivo: src/data/spells.json
   Hook UI: src/hooks/useSpells.ts  ·  Página: src/pages/SpellsPage.tsx
   Plantilla (añade un objeto al array JSON):

{
  "id": "mi-conjuro-id",
  "name": "Nombre en español",
  "nameEn": "English Name",
  "level": 0,
  "school": "evocación",
  "castingTime": "1 acción",
  "range": "9 m",
  "components": "V, S",
  "duration": "Instantáneo",
  "description": "Descripción del efecto.",
  "damage": "1d10",
  "damageType": "fuego",
  "concentration": false,
  "ritual": false,
  "classes": ["wizard", "sorcerer"]
}

--------------------------------------------------------------------------------
2) OBJETOS / ARMAS / ARMADURAS
   Archivo: src/data/items.json
   Catálogo armas (elecciones): src/data/weaponCatalog.ts
   Catálogo armaduras (CA): src/data/armorCatalog.ts
   Hook UI: src/hooks/useItems.ts  ·  Página: src/pages/ItemsPage.tsx
   Plantilla ítem:

{
  "id": "mi-objeto-id",
  "name": "Nombre",
  "nameEn": "English Name",
  "type": "weapon",
  "rarity": "common",
  "description": "Descripción.",
  "damage": "1d8",
  "damageType": "cortante",
  "properties": ["versátil (1d10)"],
  "armorClass": "14",
  "armorDexMod": "max2",
  "weight": 1,
  "cost": "15 gp",
  "attunement": false
}

  type suele ser: weapon | armor | potion | wondrous | ring | gear | tool
  armorDexMod: none | full | max2 | max3

5) CLASES (y subclases)
   Archivo principal: src/data/classes.json
   Subclases extra 2024: src/data/subclasses2024.ts
   Hook UI: src/hooks/useClasses.ts  ·  Página: src/pages/ClassesPage.tsx
   Plantilla rasgo de clase:

{
  "id": "mi-rasgo",
  "name": "Nombre del rasgo",
  "level": 1,
  "description": "Descripción.",
  "actionType": "passive",
  "uses": { "max": 1, "recovery": "short" }
}

  actionType: passive | action | bonus | reaction | special
  recovery: short | long | dawn

================================================================================
NOTAS
- Los homebrew creados en la app se guardan en localStorage (claves dnd-homebrew-*).
- Tras editar JSON a mano: guarda el archivo y ejecuta `npm run build` (o `npm run dev`).
- Mantén IDs únicos (sin espacios; usa guiones).
- nameEn es opcional pero útil para buscar en inglés.
